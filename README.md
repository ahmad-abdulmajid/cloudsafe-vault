# CloudSafe Vault

Secure file sharing and storage on AWS.

## Project Overview
CloudSafe Vault is a cloud-based web application that allows users to upload,
store, and securely share files using temporary links.  
The system is designed to reduce unauthorized access by using time-limited
pre-signed URLs.

## Project Goals
- Secure file storage per user
- Temporary and controlled file sharing
- Prevent unauthorized access
- Simple and user-friendly web interface

## Technologies Used
- AWS S3 (file storage)
- AWS CloudFront (content delivery & HTTPS)
- AWS Cognito (user authentication)
- AWS DynamoDB (file metadata)
- AWS IAM (access control)
- HTML, CSS, JavaScript
